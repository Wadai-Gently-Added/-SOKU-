# 束 -SOKU-

AI File Bundle & Transfer Control Tool

---

## Version

v0.1

---

## 概要

大量のファイルをAIへ渡す前に、

- ファイル構造を保持
- ファイルを整理
- 内容を結合
- AI用サイズへ分割
- コピー進捗を管理

するためのツールです。

「AIへ大量の資料を渡す前の面倒な整理・搬送作業」を
できるだけ自動化することを目的としています。

---

# 現在の実装

## 機能01：フォルダ投入

フォルダを丸ごと投入できます。

### 対応内容

- フォルダを一括選択
- サブフォルダを含むファイルを取得
- 相対パスを保持
- ファイル数を表示
- ファイル一覧を表示
- ドラッグ＆ドロップに対応

取得したファイル情報は、

`window.sokuInputFiles`

に保持します。

---

## 機能02：ZIP / アーカイブ投入

ZIPファイルを投入できます。

### 対応内容

- ZIPファイルを選択
- ZIP内部を展開
- 内部のフォルダ構造を保持
- 相対パスを保持
- ファイル一覧を表示
- 展開したファイルを機能01と同じ形式で保持

ZIPを展開した後は、

「ZIPから来たファイル」

として特別扱いするのではなく、

「処理対象となるファイル集合」

として後工程へ渡せる構造を採用します。

取得結果は、

`window.sokuInputFiles`

に保持します。
