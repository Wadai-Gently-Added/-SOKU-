# 束 -SOKU-

AI File Bundle & Transfer Control Tool

## Version

v0.1

## 概要

大量のファイルをAIへ渡す前に、

- ファイル構造を保持
- ファイルを整理
- 内容を結合
- AI用サイズへ分割
- コピー進捗を管理

するためのツールです。

## 現在の実装

### 機能01：フォルダ投入

現在はフォルダ投入機能を実装しています。

- フォルダを一括選択
- サブフォルダを含むファイルを取得
- 相対パスを保持
- ファイル数を表示
- ファイル一覧を表示
